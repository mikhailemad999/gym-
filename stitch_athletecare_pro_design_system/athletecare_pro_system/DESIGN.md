## Brand & Style

This design system establishes a high-performance, clinical-grade digital environment engineered for elite athletes, coaches, and sports science practitioners. The aesthetic fuses Swiss modernist typography, editorial austerity, and technical ProMax dashboard rigor.

### Personality & Tone
- **Surgical & Precise**: Stripped of superfluous ornamentation, gamified badges, and garish neon accents. Every element communicates functional discipline.
- **Authoritative & Monolithic**: Relies on high-contrast value scales, confident scale jumps, and stark black-and-white visual weight.
- **Physical & Kinetic**: Dense data representations balanced with calculated negative space, echoing the discipline of high-level athletic training.

### Design Movement
The system operates at the intersection of **Brutalism** and **Modern Swiss Minimalism**. Visual hierarchy is communicated entirely through weight, position, crisp rule borders, and absolute values of pure black and pure white. Chromatic decoration is completely absent; system feedback, telemetry data, and status changes are expressed through typographic contrast, micro-geometry, and iconographic states.

## Colors

The system is unapologetically monochromatic. Feedback, urgency, and progression are communicated strictly through value, opacity, weight, and stroke, without the use of red, green, or amber cues.

### Palette Architecture
- **Primary (`#000000`)**: Anchors deep surface structures, terminal footers, and inverted call-to-action controls.
- **Secondary (`#FFFFFF`)**: The beacon color for prime telemetry figures, display headlines, and high-emphasis controls.
- **Neutral (`#111111`)**: The baseline container value for cards, data monitors, and active interaction frames.

### Color Rules & Application
1. **Zero Hue Permitted**: Gradients and saturated color states are forbidden. Progress bars utilize solid `#FFFFFF` fill against `#202020` track containers.
2. **State & Alert Differentiation**: Alerts rely on an explicit border switch (`1px solid #FFFFFF`), inline high-visibility iconography, and bold typographic labels rather than chromatic fills.
3. **Contrast Discipline**: Body and primary labels must maintain a strict 4.5:1 minimum contrast ratio against their immediate parent surface. Muted captions (`#777777`) are reserved solely for tertiary meta-tags and static grid axis labels.

## Typography

The typographic hierarchy utilizes **Inter** across all roles to achieve a mechanized, neutral, and highly readable editorial atmosphere. 

### Editorial Display & Metrics
Headlines use tight negative tracking (`-0.015em` to `-0.03em`) and heavy weights (`700–800`) to present performance statistics and directives with impact. Massive numeric figures for biometrics, wattage, and heart-rate variability sit tightly locked against their corresponding unit descriptors.

### UI Micro-Labels
All structural markers, categorical tags, and metadata chips utilize `label-sm` or `caption` styles set in structured uppercase with positive letter spacing (`0.04em` to `0.06em`).

### Directional & International Support
Typographic weights, line heights, and hierarchy levels mirror symmetrically for right-to-left scripts such as Arabic, ensuring uniform typographic density regardless of viewport direction.

## Layout & Spacing

The layout is built around an uncompromising 12-column structural grid system anchored by strict max-width thresholds. Space is used mathematically to create high-density data views without visual clutter.

### Layout Breakpoints
- **Desktop (1440px max-width envelope)**: 12-column grid, 1200px–1320px content shell, 24px gutters, and 32px–64px outer margins. Supports persistent technical sidebars (260px–280px fixed width).
- **Tablet (768px – 1024px)**: 8-column grid with 16px gutters and 24px outer margins. The sidebar collapses into an icon shelf or full-height off-canvas drawer.
- **Mobile (320px – 767px)**: 4-column flow with 12px gutters and 16px outer margins. Modules stack vertically into a focused single-column flow with a minimum interactive target size of 44px.

### Spatial Discipline
Inner container padding strictly adheres to the component scale:
- `space-xs` (6px) and `space-sm` (10px) govern micro-interactions, badge insets, and input spacing.
- `space-md` (16px) and `space-lg` (24px) govern interior data card padding and grid module gaps.
- `space-2xl` (64px) separates major operational zones and dashboard section panels.

## Elevation & Depth

Visual hierarchy is delivered entirely through **tonal layering and crisp structural borders**, avoiding diffuse drop shadows.

### Surface Tiers
1. **Canvas Base (`#000000`)**: The primary platform background.
2. **Structural Workspace (`#0A0A0A`)**: Large-format layout panels and dashboard section cavities.
3. **Card Container (`#111111`)**: Default cards, data nodes, and module blocks framed with `1px solid #242424`.
4. **Interactive Float (`#171717`)**: Dropdown lists, context sheets, and transient popovers.
5. **Modal / Critical Dialog (`#111111`)**: High-priority modules wrapped in a prominent `1px solid #FFFFFF` or `#4A4A4A` outline.

### Shadows & Lighting
- **Default State**: Surfaces sit at `box-shadow: none;`. Depth is established purely by tone and outline.
- **Floating Overlays**: High-elevation dialogs use a surgical shadow token: `box-shadow: 0 10px 30px rgba(0, 0, 0, 0.8)`.
- **Focus Rings**: Strict dual ring using `box-shadow: 0 0 0 1px #000000, 0 0 0 3px #FFFFFF`.
- **Interactive Displacements**: Cards shift `-4px` vertically along the Y-axis upon hover, accompanied by a border brightness transition from `#242424` to `#4A4A4A`.

## Shapes

The geometric framework balances technical rigidity with physical ergonomics through a curated radius scale. Extreme pills are restricted to avoid playful or soft cues, preserving a sharp, performance-focused silhouette.

### Radius Scale
- **Small (`6px`)**: Compact indicators, status chips, micro-pills, and metric counter labels.
- **Medium (`10px`)**: Action controls, form inputs, primary buttons, and tabs.
- **Large (`14px`)**: The signature envelope for all standard cards, dashboard modules, telemetry wrappers, and media blocks.
- **Extra Large (`18px`)**: Reserved exclusively for top-level modals and floating hero panels.
- **Circular (`999px`)**: Constrained strictly to user avatars and isolated circular icon anchors. Buttons and data cards never use full pill rounding.

## Components

### Buttons & Interactive Triggers
- **Primary CTA**: Solid white background (`#FFFFFF`) with deep black text (`#000000`), radius `10px`, typography `label-md`. On press, compresses slightly via `scale(0.98)` with a 150ms transition.
- **Secondary / Outline**: Solid dark background (`#111111`) with a `1px solid #D9D9D9` or `#4A4A4A` perimeter, text `#FFFFFF`. Hover brightens the border to `#FFFFFF`.
- **Ghost Action**: Transparent surface, `#FFFFFF` typography, and an inline trailing chevron that shifts `+4px` horizontally on hover.
- **Disabled State**: Fixed opacity of `0.4` with `pointer-events: none`.

### Data Cards & Telemetry Blocks
- **Construction**: `#111111` surface fill, bordered by `1px solid #242424`, rounded to `14px`, padded with `24px` (`space-lg`).
- **Telemetry Display**: Metric label at top in uppercase `caption` (`#777777`), followed by an oversized display figure in `#FFFFFF` (`headline-lg` or `headline-md`), anchored by a bottom horizontal stroke divider (`#202020`).
- **Interaction**: Subtle `-4px` vertical translate on hover with a border transition to `#4A4A4A`.

### Chips & Metadata Tags
- **Construction**: Height fixed to `24px` or `28px`, radius `6px`, padding `0 8px`.
- **Visuals**: Dark fill (`#171717`) with a hairline border (`1px solid #242424`). Typography uses uppercase `caption` with `0.06em` tracking. No colored indicator dots; state is communicated via text and stroke weight.

### Form Inputs & Select Fields
- **Container**: Height `44px`, background `#0A0A0A`, border `1px solid #242424`, radius `10px`, typography `body-md`.
- **Placeholder**: Set to `#4A4A4A`. Text entry shifts to pure `#FFFFFF`.
- **Focus State**: Instantly shifts border to `#FFFFFF` with a high-contrast outer ring (`0 0 0 2px rgba(255, 255, 255, 0.2)`).
- **Error State**: Retains monochromatic rules via a bold high-contrast border (`2px solid #FFFFFF`) paired with an inline warning icon and clear validation copy.

### Checkboxes & Radio Controls
- **Geometry**: Checkboxes use a `4px` radius; radio buttons are circular. Sized strictly to `18px × 18px`.
- **Unchecked**: Background `#0A0A0A`, border `1.5px solid #4A4A4A`.
- **Checked**: Inverted solid fill (`#FFFFFF`) containing a black check glyph or inner dot (`#000000`).

### Lists, Tables & Performance Grids
- **Header**: Height `40px`, uppercase `caption` labels in `#777777`, bottom border `1px solid #202020`.
- **Rows**: Alternating or uniform `#0A0A0A` rows, height `52px`, separated by hairline dividers (`1px solid #171717`).
- **Hover**: Background shifts smoothly to `#141414` across `150ms`.

### Modals & Drawers
- **Backdrop**: Deep black with heavy opacity (`rgba(0, 0, 0, 0.85)`) and subtle blur.
- **Frame**: Centered modal with `18px` radius, `#111111` background, and a sharp `1px solid #333333` boundary.
- **Drawers**: Slide in from the right edge (or bottom on mobile) using a cubic bezier easing curve (`cubic-bezier(0.22, 1, 0.36, 1)`) over `300ms`.
